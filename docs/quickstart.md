# DoitDuck 快速开始

本文介绍如何烧录 DoitDuck 镜像、给鸭子配网、标定和操控。编译和二次开发见 [README](../README.md)。

## 安全须知

- 鸭子由 2S 锂电直接给舵机供电，电源开关在 IMU 小板上。上力后舵机会突然转动，手指不要放在关节之间。
- 第一次上力、标定站姿、试新动作时，用手扶着或吊起鸭子，放在平整、开阔的地面上。
- 随时可以点网页右上角的「急停」，或在电脑键盘上按空格键，舵机会立即卸力。
- 电池电压低于 6.6 V 时鸭子会提示，不能再上力。请先充电，不要过放。

## 准备

| 物品 | 说明 |
| --- | --- |
| 组装好的鸭子 | 15 个舵机、IMU 小板、CV610 连接板，ID 和接线见 [README](../README.md#硬件) |
| 2S 锂电 | 充满电，接 IMU 小板的电池接口 |
| 电脑 | 烧录镜像用，Linux 或 Windows |
| USB 线 | 连接 Cove-610 和电脑 |
| 手机或电脑浏览器 | 控制鸭子 |

摄像头、麦克风、喇叭、ToF 都是可选的，没接时对应的功能自动关闭，其他功能照常使用。

## 烧录镜像

1. 解压 `doitduck-image-<版本>.zip`，得到 `doitduck-image-<版本>/` 目录。
2. 用 burntool-cli 烧录目录里的 `nand_burn_table.xml`：

   ```sh
   ./burntool-cli -u -x doitduck-image-<版本>/nand_burn_table.xml
   ```

   运行后，按住 Cove-610 的 UPDATE 键，再重新上电或按 RST 键，看到 `Boot 已运行` 后松开 UPDATE。

烧录工具的下载、驱动安装和串口烧录方法见 [V610-Solution 镜像烧录](https://github.com/doit-open-org/V610-Solution/blob/main/docs/burntool.md)。

烧录后开机自动运行 DoitDuck。镜像把 SDIO1 引脚设为 `none` 模式，留给舵机总线使用，所以 LCD 和 SD 卡不能用。

## 第一次开机

### 1. 连上网络

**方法一：热点配网**

1. 还没配过网的鸭子开机后会自动打开无密码热点 `DoitDuck-xxxx`。以后要换网络，对鸭子说「开始配网」再打开。
2. 手机连上这个热点，设置页面会自动弹出；没弹出就在浏览器打开 `http://192.168.4.1/`。
3. 选择家里的 Wi-Fi，输入密码并连接。页面会显示连接状态，密码错了可以改了再连。
4. 连上后，页面弹窗显示鸭子的 IP 地址。记下这个地址，以后用 `http://<IP>/` 打开控制页面。

以后开机会自动连接这个 Wi-Fi。

**方法二：蓝牙配网**

热点打开时，鸭子也会用蓝牙广播 `BLUFI-DoitDuck-xxxx`。

1. 手机安装乐鑫的 EspBlufi App，打开蓝牙。
2. 在 App 里扫描并连接 `BLUFI-DoitDuck-xxxx`，选择配网，填入 Wi-Fi 名称和密码。
3. App 显示连接成功后，鸭子会播报自己的 IP 地址。

**方法三：USB 连接**（热点和蓝牙都连不上时）

1. 用 USB 线连接 Cove-610 和电脑。
2. 电脑上找到新出现的 USB 网卡，设置 IP 为 `192.168.137.1`，子网掩码 `255.255.255.0`。
3. 浏览器打开 `http://192.168.137.2/`，在「设置 → Wi-Fi」里连接家里的 Wi-Fi。

### 2. 标定

新组装或换过舵机的鸭子都要标定。打开「维护 → 标定向导」，按顺序完成：

1. **舵机检查**：确认 15 个舵机和 IMU 都显示在线。
2. **IMU 零偏**：把鸭子静止放 2 秒。
3. **零位**：把鸭子摆成标定姿势：两腿伸直、头朝前。可以先卸力，用手摆好后一次记录；也可以上力后用滑块逐个调。
4. **站姿**：把鸭子放到地上站好，按页面建议微调，再把当前姿态设为水平。

标定数据保存在鸭子里，重启后不用重新标定。「维护」页可以导出、导入和撤销标定数据。

### 3. 开始行走

打开「控制」页，把模式切到「行走」：

- 左摇杆控制前进、后退和平移，右摇杆控制转向。
- 技能按钮可以让鸭子捡东西、翻跟头。
- 电脑上也可以用键盘：W/S 前后，A/D 平移，Q/E 转向，空格急停。

鸭子摔倒后会自动起身。

## 控制页面

在浏览器打开 `http://<IP>/`，手机和电脑都能用。左上角按钮切换中英文，浅色和深色主题跟随系统。

| 页面 | 内容 |
| --- | --- |
| 控制 | 摄像头画面、模式切换、双摇杆、技能按钮、语音命令条 |
| 动作 | 导入、验证、删除动作模型 |
| 状态 | 姿态、舵机角度和在线情况、电池、IMU、ToF 距离图 |
| 维护 | 标定向导、舵机工具（扫描、改 ID、增益）、标定数据导出和导入 |
| 设置 | Wi-Fi、动作平滑、音量和叫声、小智、语音命令和手势一览、版本和许可 |

模式说明：

| 模式 | 说明 |
| --- | --- |
| 卸力 | 舵机不出力，可以用手摆动关节 |
| 仅推理 | 运行动作模型但不驱动舵机，用于检查 |
| 站好 | 保持默认站姿 |
| 行走 | 用摇杆或命令控制行走 |

## 语音和小智

需要接麦克风和喇叭，并且鸭子已经连上网络。

### 第一次激活小智

1. 打开「设置 → 小智」，页面会显示一个 6 位激活码。
2. 在 [xiaozhi.me](https://xiaozhi.me) 控制台添加设备，输入这个激活码。

### 对话

说「你好小鸭」唤醒，然后直接和小智对话。可以让它控制鸭子，比如“往前走几步”“翻个跟头”“抬头看看”，大模型会让鸭子行走、转向、做技能、动头和嘴。

### 语音命令

不用唤醒就能直接说的命令词：

| 命令词 | 作用 |
| --- | --- |
| 开始配网 | 打开配网热点 |

「控制」页的语音命令条还可以点选这些命令：站住别动、放松一下、站起来、向前走、向后退、往左边走、往右边走、向左转、向右转、原地转圈、捡起东西、翻个跟头、抬起头、低下头、看左边、看右边、看前面、张开嘴巴、合上嘴巴。完整列表见「设置」页。

## 手势

需要接摄像头。对着摄像头做手势：

| 手势 | 鸭子的反应 |
| --- | --- |
| 点赞 | 点头 |
| 张开手掌 | 张嘴 |
| 握拳 | 闭嘴 |

## 叫声

鸭子在被唤醒、执行或拒绝命令、摔倒、电量低、急停时会叫，站着 2 分钟没人理时也会每隔一两分钟叫一声。在「设置」页可以：

- 调节音量
- 关掉主动叫
- 上传自己的录音替换叫声（16 kHz 单声道 WAV）

## 热点

鸭子已经连上 Wi-Fi 时也可以打开热点，原来的连接不会断开。在「设置 → Wi-Fi」点「热点配网」，或说「开始配网」。

- 没有操作时，热点 10 分钟后自动关闭。
- 勾选「热点常开」后热点一直开着，开机也自动打开。外出没有路由器时，手机连上热点 `DoitDuck-xxxx`，打开 `http://192.168.4.1/` 就能控制。

## 动作模型

行走、起身、捡东西、翻跟头分别由不同的动作模型完成。导入新的动作模型：

1. 打开「动作」页，点「导入动作」，选择动作的 `policy.onnx` 和 `manifest.json`（Microduck schema 2）。
2. 新导入的动作标为「未验证」，只能从网页触发。先卸力，在「仅推理」模式下运行，看关节目标曲线是否平稳，这时舵机不会动。
3. 确认没问题后标为「已验证」，语音和小智才能使用。
4. 替换行走、起身动作前，要先切到「卸力」。

使用别人发布的模型前，请先看清它的许可证。

## 登录板子

需要查看日志或手动维护时，可以用 SSH 登录：

```sh
ssh root@<IP>
```

用户 `root`，默认密码 `123456`。默认密码只适合调试，请登录后用 `passwd` 修改。

DoitDuck 安装在 `/root/doitduck/`。零位、IMU 水平、导入的动作、小智设备号等数据保存在 `/root/doitduck/data/`。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示「电池电量低，请充电后再上力」 | 电池低于 6.6 V，请充电 |
| 标定时有舵机或 IMU 不在线 | 检查总线线缆、舵机 ID 和电池供电，在「维护 → 舵机工具」里扫描总线 |
| 手机连上热点后没有弹出设置页 | 在浏览器打开 `http://192.168.4.1/` |
| 忘了鸭子的 IP | 用 USB 连接电脑打开 `http://192.168.137.2/`，或在路由器的设备列表里找 |
| 说「你好小鸭」没反应 | 确认已接麦克风；小智需要先连网并在 xiaozhi.me 激活 |
| 没有摄像头画面或手势不起作用 | 确认已接摄像头 |
| 站立时向一侧倒 | 重新做「维护 → 标定向导」的站姿和水平 |
