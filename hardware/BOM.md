# 物料清单

做一只 DoitDuck 需要的硬件。两块自制板的完整元件（电阻、电容等）见各自的原理图。

## 整机

| 物料           | 型号                                | 数量       | 说明                              |
| -------------- | ----------------------------------- | ---------- | --------------------------------- |
| 主控           | Cove-610（Hi3516CV610）             | 1          |                                   |
| 串口总线舵机   | 飞特 HD1910                         | 15         | ID 见 [README](../README.md#硬件)  |
| IMU 小板       | 自制，见下文                        | 1          | 固定在躯干上，挂在舵机总线上；电池、电源开关也在这块板上 |
| CV610 连接板   | 自制，见下文                        | 1          | 插在 Cove-610 上，主控 UART1 转半双工舵机总线 |
| 电池           | 2S 锂电（标称 7.4 V，满电 8.4 V）   | 1          | 接 IMU 小板的电池接口，经开关给舵机总线供电 |
| 舵机线 | 3P 总线舵机线 | 按骨架资料 | 两块自制板的总线插座和舵机一样（A2007WR-3P，2.0 mm 3P） |
| 骨架           | 3D 打印件一套，以及配套的轴承、螺丝 | 1 套       | 见下文「骨架」                    |

## IMU 小板

原理图：[imu_board.pdf](imu_board.pdf)（DoitDuck IMU v1.0）

| 位号           | 型号                    | 数量 | 说明                                                       |
| -------------- | ----------------------- | ---- | ---------------------------------------------------------- |
| U1             | ESP32-C2（ESP8684）     | 1    | 原理图上没有外置 Flash，要选带内置 Flash 的型号            |
| U2             | LSM6DSV16XTR            | 1    | IMU，SPI                                                   |
| U4             | SN74LVC2G125DCUR        | 1    | 总线收发                                                   |
| U9             | BL1117-33CX             | 1    | 8.4 V 转 3.3 V                                             |
| X2             | 26 MHz 晶振             | 1    |                                                            |
| D1             | PESD5V0S1BA             | 1    | 总线 ESD 保护                                              |
| CN1、CN3、CN4  | A2007WR-3P              | 3    | 舵机总线插座，和舵机接口相同                               |
| CN2            | ZX-XH2.54-2PWZ          | 1    | 电池接口，XH2.54 2P                                        |
| DC-44A         | DC 插座                 | 1    | 原理图标为 DC 充电口，和电池接口并联                       |
| U8             | SS12D10G6-WJ            | 1    | 电源开关：电池接通后给本板和舵机总线（DXL_VDD）供电        |
| LED1           | LED                     | 1    | 测试灯，接 GPIO18                                          |
| LED2           | LED                     | 1    | 3.3 V 电源指示                                             |

板上没有下载接口和按键，留有烧录测试点：VCC、GND、TX、RX、RESET、BOOT。R10（总线上拉）是预留位置。

## CV610 连接板

原理图：[cv610_board.pdf](cv610_board.pdf)（DoitDuck CV610 v1.0）

| 位号 | 型号                    | 数量 | 说明                                                       |
| ---- | ----------------------- | ---- | ---------------------------------------------------------- |
| H3   | PM254-2-12-Z-8.5        | 1    | 2×12 排母，插到 Cove-610 上                                |
| U4   | SN74LVC2G125DCUR        | 1    | 总线收发，1OE# 接 DXL_TX_EN（发送使能，低电平发送）        |
| U1   | TPS54302DDCR            | 1    | 舵机总线电源（DXL_VDD）降压到 3.3 V，接到排母的 3.3 V 引脚 |
| L2   | 6.8 µH 电感             | 1    | 降压电感                                                   |
| CN4  | A2007WR-3P              | 1    | 舵机总线插座，和舵机接口相同                               |
| CN2  | LAIL-PHC2.0-4P          | 1    | 测距接口：3.3 V、GND、TOF_SDA、TOF_SCL                     |

R8、R9（TPS54302 使能分压）不焊，原理图注明悬空。

## 骨架

用 Microduck 官方骨架，如 [kissqy/Microduck-kissqy](https://github.com/kissqy/Microduck-kissqy) 的打印件。打印文件、轴承和螺丝的数量以该项目的 `DUCK-SHOPPING-LIST.md` 为准。
